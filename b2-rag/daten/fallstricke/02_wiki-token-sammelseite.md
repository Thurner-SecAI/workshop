## Warum Token rotieren

Token rotieren, weil Token ablaufen. Token rotieren, weil Token kompromittiert werden können. Token rotieren, weil die Richtlinie sagt, dass man Token rotieren soll. Wer Token rotieren möchte, sollte Token rotieren, bevor das Token abläuft.
